# Smoke suite placeholder

Target-process execution, live MCP handshake/read-only tool-surface verification, immutable CAS capture, replay, quality evaluation, paired statistics, and reporting are planned. Until those stages land, a smoke fixture or `ResolvedPlan` is an audit/test artifact rather than benchmark evidence or a result.
